# COACH · Lebens-Ordner System
MIT Lizenz © iki1uc

## Was es ist
Ein Ordner-System für dein Leben. Vier Bereiche. Jeder Bereich
eine Datei. Du liest sie. Du füllst sie. Du lebst sie.

Kein Vortrag. Kein Zwang. Nur Ordnung, wenn du sie willst.

## Die vier Dateien

mobilität.txt     Auto · Fahrrad · ÖPNV · Reisen · Pendeln
wohnen.txt        Miete · Haushalt · Nachbarn · Energie
arbeit.txt        Job · Bewerbung · Team · Chef · Geld
persönlichkeit.txt  Gesundheit · Ziele · Stress · Soziales

Jede Datei: 8 Zeilen. Eine pro Thema. Nichts mehr.

## Wie du sie benutzt
1. Öffne eine Datei
2. Lies eine Zeile
3. Frage dich: betrifft mich das heute?
4. Wenn ja → anfassen. Wenn nein → weiter.
5. Nächste Zeile.

Kein Zwang, alle zu lesen. Kein Zwang, alles zu füllen.

## Wie es sich füllt
Jede Zeile bekommt einen Wert:
   . = leer, betrifft mich gerade nicht
   o = offen, will ich bearbeiten
   ✓ = erledigt, im Griff

Nach einer Woche siehst du, wo du stehst. Nicht durch Zahlen.
Durch Punkte, Kreise, Häkchen. Ehrlich.

## Was es NICHT ist
- Kein Tagebuch
- Kein Terminplaner
- Kein Selbstoptimierungsprogramm
- Kein Coach, der dir sagt, was du tun sollst

## Was es IST
- Ein Spiegel
- Ein Filter gegen Chaos
- Eine Art, sich selbst zu sehen
- Etwas, das du allein nutzt

## Hilfe
Wenn eine Zeile hakt → `coach <thema>` öffnet das Hilfe-Modul.
Wenn nichts mehr geht → `reset` gibt dir einen leeren Start zurück.
Kein Urteil. Nur wieder bei Null.
